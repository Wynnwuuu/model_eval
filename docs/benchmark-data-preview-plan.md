# Benchmark 数据预览功能规划

## 目标

新增一种不做模型优劣评测的任务类型：Benchmark 数据预览。用户上传 CSV 后选择输入列、输出列和可选维度列，创建一个可共享的预览任务。进入执行页时逐条查看输入与输出内容，可前后切换，并可为每条数据留下评论。

该能力用于快速检查 benchmark 数据、样本质量、产物字段和媒体链接，不产生 A/B、打分或排序结论。

## 产品形态

1. 在“评测方式与评分标准”中新增“Benchmark 数据预览”。
2. CSV 字段映射仍复用现有任务构建器：
   - 输入列：prompt、用户输入、图片、音频、上下文等。
   - 输出预览列：模型输出、标准答案、生成产物、参考内容等，可多选。
   - 维度列：场景、能力、难度、来源等，仅用于展示和后续过滤分析。
3. 创建任务后，执行页不展示投票按钮，仅展示：
   - 当前 case 的输入信息。
   - 多个输出字段的预览卡片。
   - 评论输入框。
   - 保存评论并下一条、跳过、结束预览。
4. 结果页展示预览进度、评论数量、逐 case 评论明细，并支持 CSV 导出。

## 数据模型

复用现有任务、任务 item、用户 votes 存储链路：

- `evaluationConfig.method = benchmark_preview`
- `paradigm = BenchmarkPreview`
- `models` 复用为输出列列表，表示需要预览的输出字段。
- `items[].modelOutputs` 存储多输出列内容。
- `VoteRecord` 中：
  - `method = benchmark_preview`
  - `choice = previewed | skipped`
  - `reason` 存储评论文本

这样可以继续复用 PostgreSQL/API 的 `eval_tasks`、`eval_task_items`、`eval_task_user_votes` 链路，不新增表。

## 分阶段执行

### 阶段 1：方法与创建流程

- 新增 `benchmark_preview` method 与 `BenchmarkPreview` paradigm。
- 任务构建器允许该模式选择 1 个以上输出列。
- 该模式隐藏盲测、平局、Rubric、评分维度配置。
- 验收：
  - 上传 CSV 后可选择输入列和输出预览列。
  - 可创建 benchmark 预览任务。
  - 任务详情中可以看到 item 与输出列映射。

### 阶段 2：执行页预览

- 新增 comment-only 预览页面。
- 输出内容支持文本、markdown、图片、视频、音频链接的基础预览。
- 支持上一条、下一条、跳过、保存评论。
- 验收：
  - 从任务列表进入执行页不会出现 A/B 投票界面。
  - 保存评论后自动进入下一条。
  - 刷新或直接访问任务 URL 后仍能按已保存进度恢复。

### 阶段 3：结果页与导出

- 结果页对 `benchmark_preview` 单独展示预览统计，不进入模型胜负洞察。
- CSV 导出包含输入摘要、维度、输出列、状态、评论、用户和时间。
- 验收：
  - 完成或提前结束预览后进入结果页。
  - 结果页不显示胜率、平局等评测统计。
  - 下载 CSV 可看到评论与输出字段。

### 阶段 4：后续增强

- 增加过滤器：按维度、是否已评论、媒体加载失败筛选。
- 增加批注类型：问题、通过、需复核、字段错误。
- 增加数据质量摘要：空值率、链接格式异常、输出列覆盖率。
- 支持从预览任务一键生成正式评测任务。
